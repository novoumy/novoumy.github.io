# Vector icon sources

- Social platform marks: `simple-icons` (official, recognizable brand marks rendered as inline SVG paths).
- PC component and peripheral pictograms: `lucide-react` (clean, rounded 2D outline SVG icons).
- All replacement artwork is rendered in the site's existing purple, `#3A2272`; no platform-specific or custom accent colors are applied.

The four top navigation tabs, the Main / Socials / Specs / Interests navigation icons, and the email icon in the Socials view are intentionally not changed.
